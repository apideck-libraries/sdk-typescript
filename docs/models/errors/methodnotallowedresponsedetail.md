# MethodNotAllowedResponseDetail

Which operation the connector does not support, and why.

## Example Usage

```typescript
import { MethodNotAllowedResponseDetail } from "@apideck/unify/models/errors";

let value: MethodNotAllowedResponseDetail = {
  context: "Myob does not currently support creditNotesDelete.",
  error:
    "MYOB has no direct credit note deletion endpoint. Delete a credit note by deleting the underlying invoice via the invoices endpoint.",
};
```
