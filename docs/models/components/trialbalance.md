# TrialBalance

The balance of every ledger account as of a date, split into debit and credit columns. Balance sheet accounts are cumulative to `end_date`; income and expense accounts are year-to-date within the fiscal year that contains `end_date`.

## Example Usage

```typescript
import { TrialBalance } from "@apideck/unify/models/components";

let value: TrialBalance = {
  reportName: "Trial Balance",
  startDate: "2025-01-01",
  endDate: "2025-12-31",
  currency: "USD",
  accounts: [],
  totalDebit: 98250,
  totalCredit: 98250,
};
```
