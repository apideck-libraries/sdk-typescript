# GoodsReceiptLineCreateInput

A line of a goods receipt create request: the quantity received against one line of the purchase order. Every line is linked to a purchase order line; a receipt line without one cannot be created.

## Example Usage

```typescript
import { GoodsReceiptLineCreateInput } from "@apideck/unify/models/components";

let value: GoodsReceiptLineCreateInput = {
  purchaseOrder: {
    id: "123456",
    lineId: "123456",
    lineNumber: "1",
  },
  quantityReceived: 4,
  unitOfMeasure: "pc.",
  description: "Pallet 1 of 2",
  locationId: "1710/171A",
};
```
