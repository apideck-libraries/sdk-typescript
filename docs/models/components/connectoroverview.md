# ConnectorOverview

Editorial overview metadata for the connector, used to render the connector's Overview documentation (implementation difficulty, partnership requirements, sandbox availability, and other at-a-glance facts).

## Example Usage

```typescript
import { ConnectorOverview } from "@apideck/unify/models/components";

let value: ConnectorOverview = {
  beta: false,
  demo: false,
  difficulty: "moderate",
  difficultyReason: "Self-Service Signup + App Review Required",
  partnershipRequired: true,
  apideckCredentialsAvailable: true,
  accountTypeRequired: "<value>",
  sandboxAvailable: true,
  consumerAccessLevel: "<value>",
};
```
