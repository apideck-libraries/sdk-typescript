# FixedAsset

For an account that holds the cost of fixed assets, the fixed-asset register's figures for the assets recorded in it. Null for other accounts, including accumulated-depreciation accounts, and when the accounting system does not provide them.

## Example Usage

```typescript
import { FixedAsset } from "@apideck/unify/models/components";

let value: FixedAsset = {
  cost: 13495,
  accumulatedDepreciation: 1000,
  acquisitionDate: new Date("2026-01-01"),
  depreciationMethod: "straight_line",
  downstreamDepreciationMethod: "StraightLine",
  usefulLifeMonths: 60,
};
```
