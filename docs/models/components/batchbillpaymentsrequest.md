# BatchBillPaymentsRequest

A batch of bill payments to write in a single request. Each item is processed independently: some may succeed while others fail, and the response carries one result per item in the order they were sent.

## Example Usage

```typescript
import { BatchBillPaymentsRequest } from "@apideck/unify/models/components";

let value: BatchBillPaymentsRequest = {
  items: [],
};
```
