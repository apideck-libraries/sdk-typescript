# Accounting.FiscalPeriods

## Overview

### Available Operations

* [list](#list) - List Fiscal Periods
* [get](#get) - Get Fiscal Period

## list

List the fiscal (accounting) periods of the company, with their dates and whether they are open for posting.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="accounting.fiscalPeriodsAll" method="get" path="/accounting/fiscal-periods" -->
```typescript

const apideck = new Apideck({
  consumerId: "test-consumer",
  appId: "dSBdXd2H6Mqwfg0atXHXYcysLJE9qyn1VwBtXHX",
  apiKey: process.env["APIDECK_API_KEY"] ?? "",
});

async function run() {
  const result = await apideck.accounting.fiscalPeriods.list({
    serviceId: "salesforce",
    companyId: "12345",
    passThrough: {
      "search": "San Francisco",
    },
    fields: "id,updated_at",
  });

  for await (const page of result) {
    console.log(page);
  }
}

run();
```
